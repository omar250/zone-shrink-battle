# Zone Shrink Battle

لعبة أندرويد أكشن مصغرة مستوحاة من الباتل رويال: منظور علوي، أسلحة تلتقطها من الأرض، 24 عدواً بالذكاء الاصطناعي، ودائرة آمنة تضيق تدريجياً. آخر من يبقى حياً يفوز.

## تحميل اللعبة

1. افتح صفحة **Releases** في هذا المستودع.
2. نزّل ملف `ZoneShrinkBattle.apk` من إصدار `latest`.
3. افتحه على الهاتف وفعّل خيار "التثبيت من مصادر غير معروفة" إذا طُلب منك.

يُبنى الملف تلقائياً بواسطة GitHub Actions بعد كل رفع على الفرع `main` (يستغرق نحو 3 إلى 5 دقائق).

## التحكم

- **النصف الأيسر من الشاشة:** عصا الحركة.
- **النصف الأيمن من الشاشة:** عصا التصويب، وتطلق النار تلقائياً عند سحبها لمسافة كافية.
- **زر "تبديل" أعلى اليمين:** لتبديل السلاح.

## الأسلحة

| السلاح | الميزة |
|---|---|
| مسدس | ذخيرة غير محدودة، ويبدأ به اللاعب |
| رشاش | معدل إطلاق عالٍ ودقة أقل |
| بندقية | متوازنة ومدى جيد |
| شوتغن | قوي جداً من مسافة قريبة |
| قناصة | ضرر عالٍ ومدى بعيد وإطلاق بطيء |

التقط الأسلحة والذخيرة وحزم الصحة بالمرور فوقها. الأعداء يسقطون أسلحتهم عند موتهم.

## البناء محلياً

افتح المشروع في Android Studio واضغط Run، أو نفّذ `gradle assembleDebug` (يلزم Gradle 8.7 أو أحدث وJDK 17).

## خطط مستقبلية

- لعب جماعي محلي بين هواتف قريبة عبر Nearby Connections.
- أصوات ومؤثرات.
