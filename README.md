# Zone Shrink Battle (3D)

لعبة أندرويد باتل رويال مصغرة بثلاثية الأبعاد (Low-poly) وكاميرا خلف الشخصية: 20 عدواً بالذكاء الاصطناعي، أسلحة تلتقطها من الأرض، ودائرة آمنة تضيق تدريجياً. آخر من يبقى حياً يفوز.

كل المجسمات والألوان تُرسم بالكود عبر OpenGL ES 2.0، ولا توجد ملفات صور أو نماذج.

## تحميل اللعبة

1. افتح صفحة **Releases** في هذا المستودع.
2. نزّل `ZoneShrinkBattle.apk` من الإصدار `latest`.
3. ثبّته على هاتفك (فعّل "التثبيت من مصادر غير معروفة" إن طُلب).

يُبنى الملف تلقائياً بواسطة GitHub Actions بعد كل رفع على الفرع `main`.

## التحكم

- **الجانب الأيسر من الشاشة:** عصا الحركة (الحركة نسبة لاتجاه الكاميرا).
- **السحب على الجانب الأيمن:** تدوير الكاميرا والتصويب.
- **زر "نار":** إطلاق النار (يمكنك تحريك إصبعك عليه أيضاً لتدوير الكاميرا).
- **زر "تبديل":** تبديل السلاح.

يوجد مساعد تصويب خفيف عند إطلاق النار نحو عدو أمامك.

## الأسلحة

| السلاح | الميزة |
|---|---|
| مسدس | ذخيرة غير محدودة، ويبدأ به اللاعب |
| رشاش | معدل إطلاق عالٍ ودقة أقل |
| بندقية | متوازنة ومدى جيد |
| شوتغن | قوي جداً من مسافة قريبة |
| قناصة | ضرر عالٍ ومدى بعيد وإطلاق بطيء |

يمكنك رؤية أضواء ملونة فوق الأسلحة وحزم الصحة والذخيرة من بعيد. الأعداء يسقطون أسلحتهم عند موتهم.

## البناء محلياً

افتح المشروع في Android Studio وشغّله، أو نفّذ `gradle assembleDebug` (يلزم Gradle 8.7 أو أحدث وJDK 17).

## خطط مستقبلية

- لعب جماعي محلي بين هواتف قريبة عبر Nearby Connections.
- أصوات ومؤثرات.
